# Innov8IT Task Management System

## Overview

A modern project and task management platform inspired by ClickUp, Linear, and Asana.

The system allows teams to manage projects, tasks, deadlines, assignments, comments, and activity tracking from a centralized dashboard.

---

## Objectives

- Improve team productivity
- Centralize project management
- Track project progress
- Improve collaboration
- Reduce manual task monitoring

---

## User Roles

### Admin

- Manage workspace
- Manage projects
- Manage users
- View analytics

### Team Member

- View projects
- Create tasks
- Update assigned tasks
- Comment on tasks
